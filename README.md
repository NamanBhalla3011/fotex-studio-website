# Fotex Studio website

A responsive, multi-page photography-studio website. Open `index.html` in a browser to preview it locally.

## Pages

Home, About, Services, Weddings, Commercial, Gallery, Packages, Testimonials, Journal, FAQ, and Contact.

## Before launch

Replace the placeholder contact details, social URLs, image URLs, and `https://fotexstudio.com` with the real business information. The `robots.txt`, `sitemap.xml`, metadata, canonical URLs, and homepage LocalBusiness schema are ready for this domain.
